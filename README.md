# SarthiGo - Car Rental Web App
Django + Tailwind CSS (CDN) + SQLite. Run these in the folder with manage.py:

    pip install -r requirements.txt
    python manage.py makemigrations rentals
    python manage.py migrate
    python manage.py seed_cars
    python manage.py createsuperuser
    python manage.py runserver

Open http://127.0.0.1:8000/  (staff dashboard: /admin-dashboard/, Django admin: /admin/)
Log in with the superuser account to see the Admin Dashboard link.
